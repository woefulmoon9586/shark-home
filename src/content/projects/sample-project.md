## 简介

这是你现在看到的这个网站！一个极客风格的个人主页，包含博客、项目展示和自我介绍。

## 功能特性

- 暗色终端美学风格
- 响应式设计，适配各种设备
- Markdown 写博客和项目介绍
- 零 JavaScript 运行时，加载速度极快

## 技术细节

使用 Astro 5 的 Content Collections 管理内容，Tailwind CSS 4 的 `@theme` 自定义暗色配色。全部静态生成，无需服务端。
